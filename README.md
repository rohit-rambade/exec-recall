# Exec Recall website

A small static website that turns Markdown files into a notes site with:

- a home page with one card per technology and your revision progress
- a sidebar of topics, an "On this page" contents list and previous/next links
- search across every topic (Ctrl+K or /)
- light and dark themes
- code highlighting (C#, SQL, JS, Python and more) with a Copy button
- tick-able checklists and a "Mark as revised" button, saved in your browser
- Mermaid diagrams in ```` ```mermaid ```` blocks

## Folder layout

```
tech-notes/
├─ index.html          ← open this
├─ site-data.js        ← generated by build.js (don't edit)
├─ build.js            ← run after adding or changing .md files
├─ assets/             ← app.js and style.css
└─ content/
   ├─ _site.json       ← site title and home-page text
   ├─ csharp/
   │  ├─ _meta.json    ← title, description, icon, colour, topic order
   │  └─ *.md          ← one topic per file
   └─ sql/
      ├─ _meta.json
      └─ *.md
```

## Use it

You need Node.js (any recent version).

```bash
node build.js            # build once
node build.js --watch    # rebuild automatically while you edit
```

Then double-click `index.html`. No web server is needed, because the build puts all the notes into `site-data.js`.

## Add your C# notes

1. Open the C# revision doc, open a tab, then click the doc's name and choose **Export → Markdown**.
2. Save the file into `content/csharp/` (keep the exported name, e.g. `LINQ.md`).
3. Repeat for the other tabs, then run `node build.js`.

The topic order is already listed in `content/csharp/_meta.json`, so exported tabs line up in course order automatically.

## Add a new technology (SQL, Angular, Azure…)

1. Create a folder: `content/angular/`
2. Optional: add `content/angular/_meta.json`

   ```json
   {
     "title": "Angular",
     "description": "Components, services, RxJS and routing.",
     "icon": "NG",
     "color": "#dd0031",
     "position": 3
   }
   ```

3. Add `.md` files and run `node build.js`.

## Ordering topics

The first rule that matches wins:

1. Front matter at the top of the file:
   ```
   ---
   title: Joins
   order: 2
   ---
   ```
2. The `"order"` list in `_meta.json` (matches the page title or file name).
3. A number prefix on the file name: `01-basics.md`, `02-joins.md`.
4. Alphabetical.

Files starting with `_` are ignored.

## Publish it online (optional)

The folder is a plain static site. Push it to a GitHub repo and turn on **GitHub Pages**, or drag the folder into Netlify. Remember to run `node build.js` before you publish.

Progress ticks are stored in each browser's local storage, so they don't sync between devices.
